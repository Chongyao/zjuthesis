\section{研究目标、内容和拟解决的关键问题}

\subsection{研究目标}

建立一套基于基函数重构的软硬耦合问题求解理论框架，实现高效、鲁棒的物理仿真。具体目标包括：

\begin{enumerate}
  \item 建立基函数重构的统一理论框架，阐明其与传统方法的本质区别
  \item 发展针对不同类型软硬耦合问题的专用基函数设计方法
  \item 实现近线性复杂度的高效求解算法
  \item 验证方法在典型应用场景中的有效性和实用性
\end{enumerate}

\subsection{研究内容}

本研究的核心思想是通过定制化的基函数与坐标变换，在新的表示子空间内"吸收"或"剥离"系统的硬约束与病态特征。具体而言，与其在极度病态的原始物理节点空间中求解，不如将物理系统映射到一个能够自然兼容硬约束或过滤高频伪模式的全新基底中。

\subsubsection{研究内容一：不可拉伸弹性棒仿真（一维极度耦合）}

对于一维细长弹性结构（如毛发、绳索、缝合线等），其核心的软硬耦合体现在长度的绝对"不可伸长性"（无穷大拉伸刚度）与极小的弯曲/扭转刚度之间的矛盾。在传统的有限元或基于节点的表示方法中，为了描述Cosserat杆的空间位姿，往往需要保留冗余的节点坐标和姿态四元数，并通过海量的几何非线性方程来硬性约束其长度和相邻节点的对齐关系，这使得约束非线性优化问题极其僵硬和难以求解。

本研究提出了一种紧凑坐标表示（Compact Representation）方法。通过一次深度的坐标基变换，摒弃传统的节点位置自由度，转而使用基于根节点位置以及局部轴角（Axis-angle）的曲率链式参数化体系。在这一全新的坐标基底下，系统的求解维度被精确缩减至与其内蕴自由度完全一致的$3n$维。更重要的是，这种基函数变换在表示层面上天然地满足了不可伸长、四元数单位化以及局部对齐等所有硬约束，从而将一个条件极其恶劣的带约束优化问题，完美转换为了无约束的软体优化问题。

\subsubsection{研究内容二：大规模特征值问题求解（宏观全局耦合）}

在超大规模弹性系统（如大型机械部件的特征值分析或模态提取）中，系统的宏观低频柔性运动通常与各子结构界面处高频、强刚度的耦合约束交织在一起。传统的全局刚度矩阵由于维度极高，计算其极小特征对极为困难；而标准的模态综合法（CMS）虽然通过降维极大地缓解了计算压力，但其对界面约束模态的求解（即计算Schur补）在面对海量界面节点时依然极其昂贵，且容易引发精度流失。

本研究在CMS理论基础上，创新性地提出了一种基于多重划分（Primal-Dual）的相位互补模态基变换方法。将庞大的全节点物理空间映射至由不同空间划分策略提取出的降维模态子空间中。由于不同的划分方式在界面和内部节点处具有不同的频谱捕捉特性，这种多重基函数空间能够形成完美的"相位互补"。基于此，提出了无Schur补及无局部特征求解的界面模态缩减法（SE-free IMR），直接利用对偶划分中的低频模态基去近乎无损地逼近原始的界面约束空间。

\subsubsection{研究内容三：畸变单元稳定性处理（三维局部畸变）}

在三维弹性体有限元分析中，病态网格单元（特别是包含两个极度靠近顶点的Sliver Elements）会产生极大的插值误差，并导致该区域的人工刚度急剧增加，这在原本柔软的连续体中引入了严重的局部结构性病态，往往会导致预条件共轭梯度（PCG）等迭代求解器彻底停滞。

本研究首先提出了谱几何退化分析，将系统的病态条件明确划分为可通过简单预处理器缓解的"尺度病态"与由几何畸变主导的"结构性病态"。为了消除这种结构性硬耦合，提出了一种数值感知（Numeric-aware）的局部细化与聚合策略。不再使用标准的FEM节点插值多项式，而是利用局部刚度矩阵的主特征向量作为物理探针，识别出产生最强人工锁定的方向。沿着这一方向，采用基于算子自适应的基函数优化与凝聚技术，重新构造能够使得局部区域能量最小化的新插值基。

\subsection{拟解决的关键问题}

\begin{enumerate}
  \item \textbf{如何通过坐标变换消除不可拉伸弹性棒的内在约束？}
  \begin{itemize}
    \item 挑战：需要在保持物理精度的同时，将约束优化问题转化为无约束问题
    \item 解决思路：设计紧凑坐标表示，使约束在表示层面自动满足
  \end{itemize}
  
  \item \textbf{如何构造相位完备的模态基函数提升CMS收敛速度？}
  \begin{itemize}
    \item 挑战：传统CMS子结构基函数相位固定，无法有效张成目标解空间
    \item 解决思路：利用多重划分生成相位互补的基函数集合
  \end{itemize}
  
  \item \textbf{如何识别并过滤畸变单元产生的高频伪刚性模式？}
  \begin{itemize}
    \item 挑战：传统网格细化方法代价高昂且可能引入新的畸变
    \item 解决思路：通过谱分析识别病态方向，设计自适应基函数过滤
  \end{itemize}
  
  \item \textbf{如何实现近线性复杂度的高效求解？}
  \begin{itemize}
    \item 挑战：大规模稀疏系统求解通常具有超线性复杂度
    \item 解决思路：利用特殊矩阵结构设计高效预处理器
  \end{itemize}
\end{enumerate}

\section{研究的创新点}

\subsection{理论创新}

\textbf{1. 提出"基函数重构"的新范式}

区别于传统的代数预处理器方法，本研究从离散表达层面解决软硬耦合问题。核心思想是通过重新设计离散空间的基函数，在投影层面实现软硬成分的数值解耦。这一范式将"求解器优化"提升到"表达优化"的更高层次。

\textbf{2. 建立统一的理论框架}

三个研究内容（不可拉伸弹性棒、广义特征值问题、畸变单元）看似独立，实则共享统一的理论内核：通过基函数变换，将结构性病态转化为尺度病态或直接消除。本研究将首次建立这一统一的理论框架。

\textbf{3. 揭示相位完备性的数学本质}

在模态综合法研究中，首次明确指出传统CMS收敛慢的根本原因——基函数相位固定。通过多重划分实现相位完备，为CMS理论提供了新的视角。

\subsection{方法创新}

\textbf{1. 紧凑坐标表示方法}
\begin{itemize}
  \item 将约束优化问题转化为无约束问题
  \item 系统维度从$7n-4$降至$3n$，与内蕴自由度精确匹配
  \item 所有内在约束在表示层面自然满足
\end{itemize}

\textbf{2. 近线性复杂度预处理器}
\begin{itemize}
  \item 利用系统矩阵的特殊结构（块三对角）
  \item 构造对称正定的混合预处理器
  \item PCG收敛速度提升1-2个数量级
\end{itemize}

\textbf{3. 相位互补的多重划分策略}
\begin{itemize}
  \item 利用Primal-Dual空间交错划分
  \item 生成相位完备的模态基函数
  \item 精度提升3个数量级
\end{itemize}

\textbf{4. 无Schur补的IMR方法}
\begin{itemize}
  \item 避免了传统CMS中最昂贵的计算步骤
  \item 利用对偶划分的子结构模态近似界面模态
  \item 显著降低内存占用
\end{itemize}

\textbf{5. 算子自适应基函数}
\begin{itemize}
  \item 基于局部刚度矩阵主特征向量识别病态方向
  \item 通过基函数重构过滤高频伪刚性模式
  \item 在不增加系统自由度的前提下改善病态性
\end{itemize}
