\section{课题来源}

本课题来源于计算机图形学与计算物理仿真领域的前沿研究需求，受到国家自然科学基金和浙江大学研究生科研创新项目的支持。

物理模拟的系统性探索可追溯至20世纪中叶。伴随着有限元方法（Finite Element Method, FEM）在航空航天与结构工程中的萌芽，人类开始尝试利用严谨的数学工具描述宏观世界的动态演变。进入20世纪80年代末至90年代，物理模拟迎来了一个飞速发展的黄金阶段。这一过程并非单一领域的线性演进，而是两条各具特色、互为补充的技术路径并行驱动的结果。

一方面，计算机辅助工程（Computer-Aided Engineering, CAE）领域在这一时期确立了其在工业设计中的核心地位。CAE致力于通过高精度的数值方法还原物理规律，以实现对结构强度、流体动力等关键指标的可靠预测。与之并行的，是计算机图形学（Computer Graphics, CG）发生的深刻变革：研究者们意识到，传统的几何建模已难以满足日益增长的视觉表现需求，模拟的真实感必须植根于底层的物理机制。

在现代计算图形学与计算物理仿真中，弹性体及复杂结构的动力学计算面临着一个极为普遍且艰巨的挑战："软硬耦合"（Stiff-soft Coupling）问题。物理系统在不同尺度或不同组件之间往往展现出截然不同的刚度响应。例如，在一维细长杆件中，沿着轴向的拉伸刚度（无穷大硬约束）与横向的弯曲扭转刚度（极软）交织在一起；在三维连续体的有限元（FEM）分析中，局部发生几何畸变（如Sliver Elements）的网格会因为极其糟糕的单元条件数而产生巨大的人工数值刚化（Locking），与周围正常的柔软组织形成剧烈冲突；而在宏观尺度的复杂机械装备或大尺度结构动力学分析中，不同子结构交界面处的高频强耦合与子结构内部的低频柔性形变同样构成典型的软硬耦合现象。

在传统的全自由度笛卡尔坐标系或标准节点有限元基底下直接求解这些软硬耦合系统，往往会带来灾难性的数值后果。强行引入隐式拉格朗日乘子或高数值的惩罚弹簧，不仅会导致系统全局刚度矩阵的条件数（Condition Number）急剧爆炸，使得线性求解器陷入停滞，还会极大程度地限制时间积分的步长，使得高保真仿真的计算代价变得无法承受。

本课题旨在通过定制化的基函数与坐标变换方法，在不牺牲物理精确度的前提下突破这一计算瓶颈。本研究的核心思想是通过基底的变换重构，将棘手的结构性病态转化为易于处理的尺度问题，或直接在降维子空间中规避刚性维度的计算。

\section{课题的研究意义}

\subsection{面向世界科技前沿}

从计算机科学的视角来看，物理模拟的进步实质上是计算几何、数值分析、高性能计算（HPC）与数据结构等核心领域的综合交叉产物。这种多学科的交织使得研究者能够在有限的算力约束下，通过算法创新处理从微观粒子到宏观天体的跨尺度仿真任务。

迈入21世纪20年代，物理模拟的研究立意进一步升华。在具身智能（Embodied AI）与世界模型（World Models）蓬勃发展的今天，高保真的仿真环境已成为智能体理解物理法则、实现虚实迁移（Sim-to-Real）的关键"数字实验室"。值得注意的是，这一新范式对仿真算法提出了前所未有的鲁棒性要求：智能体的学习过程涉及数以万计的闭环迭代，任何微小的数值不稳定性都可能导致训练失败或物理逻辑谬误。因此，攻克物理仿真中的数值瓶颈，已从单纯的视觉追求演变为构建通用人工智能（AGI）底座的核心技术诉求。

物理仿真是计算机图形学、计算力学、机器人学等领域的核心技术，代表着世界科技前沿的发展方向。本研究提出的基函数重构方法，为构建更健壮、更高效的物理仿真系统提供了新的理论范式，对推动计算机科学在物理仿真领域的创新具有重要意义。研究成果有望在顶级国际学术会议和期刊（如SIGGRAPH、TOG、TVCG等）发表，提升我国在该领域的国际学术影响力。

\subsection{面向国家重大需求}

我国在航空航天、汽车工业、智能制造等领域对高精度物理仿真有迫切需求。传统仿真方法在处理复杂耦合系统时存在数值稳定性不足、计算效率低下等问题，严重制约了国产CAE软件的发展。目前，国际主流的CAE软件（如ANSYS、Abaqus、Nastran等）主要被欧美企业垄断，我国在自主可控CAE软件方面存在明显短板。

本研究提出的基函数重构方法可有效提升仿真系统的鲁棒性和计算效率，为我国自主CAE软件的研发提供技术支撑。具体体现在以下几个方面：

\begin{enumerate}
  \item \textbf{提升数值稳定性}：通过基函数重构消除系统的结构性病态，显著改善求解器的收敛特性，减少数值发散和计算失败的情况。
  \item \textbf{加速计算效率}：近线性复杂度的求解算法可大幅缩短仿真计算时间，提高工程设计的效率，缩短产品研发周期。
  \item \textbf{支持大规模并行}：方法天然支持分布式并行计算，可充分利用国产高性能计算资源，处理超大规模仿真问题。
  \item \textbf{促进软件自主可控}：为国产CAE软件的数值核心模块提供关键技术，减少对国外软件的依赖，增强产业链安全。
\end{enumerate}

\subsection{面向经济主战场}

物理仿真技术广泛应用于工业产品设计、虚拟现实、数字孪生、影视特效、游戏开发等产业。据统计，全球CAE软件市场规模已超过80亿美元，年增长率保持在10\%以上。在我国"十四五"规划和"中国制造2025"战略中，工业软件被列为重点发展领域。

  \item 航空航天：飞行器气动弹性分析、结构动力学仿真
  \item 电子行业：电子产品跌落仿真、热力耦合分析
  \item 文化创意：影视特效、虚拟现实游戏、数字人动画
  \item 医疗健康：手术仿真、康复器械设计、生物力学分析

在医疗仿真、手术规划、康复工程等领域，高保真物理仿真正发挥越来越重要的作用。本研究提出的鲁棒仿真方法可为医疗仿真提供更稳定、更高效的数值工具，助力精准医疗和健康产业发展。

具体应用场景包括：

  \item 康复工程：假肢和康复器械的生物力学仿真优化
  \item 药物输送：血管内药物输送的流体动力学仿真
  \item 医学教育：虚拟手术培训系统，提高医学教育质量
\end{enumerate}

\section{国内外研究现状分析}

\subsection{弹性体仿真方法研究现状}

弹性体仿真是计算机图形学和计算力学的核心问题，其研究历程可追溯至20世纪中叶。根据离散化策略的不同，主要方法可分为以下几类：

\textbf{1. 质点-弹簧模型（Mass-Spring Model）}

质点-弹簧模型是最早的弹性体仿真方法之一，其优点是计算简单、易于实现，适用于实时交互应用。然而，该方法的材料参数难以与真实物理属性对应，精度有限，难以准确模拟真实弹性体的行为。代表性工作包括Selle等人（2008）提出的大规模质点-弹簧系统。

\textbf{2. 有限元方法（Finite Element Method, FEM）}

有限元方法是目前工程应用最广泛的数值方法，具有坚实的数学理论基础和高精度特点。Hughes（2012）在《The Finite Element Method》中系统阐述了FEM的理论框架。FEM的核心思想是将连续体离散为有限个单元，通过插值函数建立单元内部的位移场，进而推导系统的刚度矩阵和质量矩阵。然而，传统FEM在处理大变形、网格畸变等问题时面临数值锁死（Locking）和网格依赖性等挑战。

\textbf{3. 边界元方法（Boundary Element Method, BEM）}

边界元方法只需在边界上离散，内部无需划分网格，特别适合无限域问题和裂纹问题。但BEM产生的矩阵是稠密的，存储和求解代价较高，且对非均匀材料处理困难。

\textbf{4. 离散元素法（Discrete Element Method, DEM）}

离散元素法将连续体离散为大量离散粒子的集合，每个粒子具有独立的质量和运动状态。该方法适合颗粒材料、岩土工程等应用，但对连续弹性体的模拟精度有限。

\textbf{5. 无网格方法（Meshless Methods）}

无网格方法如光滑粒子流体动力学（SPH）、物质点法（MPM）等，避免了网格划分的困扰，适合处理大变形和断裂问题。但无网格方法的边界条件处理和数值积分精度仍存在挑战。

近年来，研究者们提出了多种加速和稳定化技术，包括模型降维方法（Model Reduction）、自适应网格细化（Adaptive Mesh Refinement）、预处理器优化（Preconditioning）和并行计算技术（Parallel Computing）。

\subsection{细长杆仿真方法研究现状}

细长弹性结构（如毛发、绳索、缝合线等）的仿真是一个具有挑战性的问题。代表性方法包括：

\textbf{1. 传统节点表示方法}

Spillmann等人（2007, 2008, 2020）通过中心线上顶点的笛卡尔坐标表示杆的形状，用单元四元数表示材料标架。这种方法简单直观，但需要处理长度约束、四元数单位化约束和轴对齐约束等大量约束条件。

\textbf{2. Bishop标架方法}

Bergou等人（2008, 2010）提出通过沿中心线平行移动计算无扭转标架（Bishop框架），将材料标架表示为与Bishop框架的差值（扭转角）。这种表示消除了四元数和对齐约束，但单元上的伸长仍作为自由度保留。

\textbf{3. Super-Helices方法}

Bertails等人（2006）提出了一种恰好匹配不可伸长Cosserat杆内蕴自由度的表示方法，将杆离散化为不可伸长单元，每个单元的材料曲率和扭转为常数。该方法精度高，但积分过程产生稠密质量矩阵，算法复杂度为$O(N^2)$。Bertails（2009）将复杂度降至线性，但仍存在大时间步长下的稳定性问题。

\textbf{4. RedMax方法}

Wang等人（2019）提出了铰接刚体链的递归表示方法，使用块对角预处理器实现高效求解器。该方法适用于实时应用，但对碰撞等交互的处理仍有局限。

\subsection{病态问题与条件数优化研究现状}

系统病态性（Ill-conditioning）是数值仿真的核心难题，源于矩阵条件数的极端值。条件数定义为矩阵最大与最小特征值之比：$\kappa(A) = |\lambda_{\max}| / |\lambda_{\min}|$。当条件数过大时，求解器的收敛速度大幅下降，甚至因舍入误差累积而无法获得可靠解。

现有解决方案主要包括：

\textbf{1. 预处理器设计}
\begin{itemize}
  \item 不完全LU分解（ILU）：保持稀疏性的近似分解
  \item 多重网格方法（Multigrid）：利用多尺度信息加速收敛
  \item 区域分解预处理器：适合并行计算
\end{itemize}

然而，传统预处理器多为"黑盒"式代数修补，未从根本上解决离散表达与物理本质的失配问题。

\textbf{2. 正则化方法}
\begin{itemize}
  \item Tikhonov正则化：在病态矩阵中添加正则化项
  \item 截断奇异值分解（TSVD）：截断小奇异值改善条件数
\end{itemize}

正则化方法在改善条件数的同时可能损失物理精度。

\textbf{3. 基函数优化}
\begin{itemize}
  \item 谱方法：使用正交多项式作为基函数
  \item 小波方法：多分辨率分析
  \item 自适应基函数：根据问题特性调整基函数
\end{itemize}

这些方法提供了改善系统病态性的新思路，但针对软硬耦合问题的专门研究仍较为有限。

\subsection{模态综合法（CMS）研究现状}

模态综合法是解决大规模特征值问题的有效方法，起源于航空航天领域。代表性工作包括：

\textbf{1. Craig-Bampton方法}

Craig和Bampton（1968）提出了固定界面模态综合法，将子结构特征模态和界面模态组合构成缩减基。该方法几乎被应用于所有商业有限元软件（MSC Nastran、ANSYS、Abaqus等）。

\textbf{2. Craig-Chang方法}

Craig和Chang提出了自由界面模态综合法，适用于某些特定的界面配置。

\textbf{3. 界面模态缩减法（IMR）}

Kuether等人（2017）提出通过在Schur补步骤后求解局部特征问题，仅计算低频界面模态以降低计算成本。但该方法仍需执行昂贵的Schur补计算。

\textbf{4. 自动多层次子结构法（AMLS）}

Bennighof等人（2004）提出了递归应用分解的AMLS方法，实现了高效的层次化求解。

现有CMS方法的主要瓶颈：
\begin{enumerate}
  \item 子结构基底无法有效张成目标解空间，收敛速度往往不尽如人意
  \item Schur补计算代价高昂且内存密集
  \item 随着子结构特征模态数量增加，误差下降缓慢
\end{enumerate}

\subsection{本研究的切入点与创新点}

针对上述问题，本研究提出"基函数重构"的新范式，核心创新在于：

\textbf{1. 理论创新}：从离散表达层面解决软硬耦合问题，区别于传统的代数预处理器方法

\textbf{2. 方法创新}：
\begin{itemize}
  \item 紧凑坐标表示：通过坐标变换消除内在约束，将约束优化转化为无约束优化
  \item 相位互补模态基：利用多重划分实现基函数相位完备，提升收敛速度
  \item 算子自适应基函数：识别并过滤高频伪刚性模式，改善系统病态性
\end{itemize}

\textbf{3. 应用创新}：方法可广泛应用于毛发动画、模态分析、有限元仿真等领域
