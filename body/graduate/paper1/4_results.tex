\section{实验结果与分析}
我们在多组实验中评估了所提方法的性能。所有实验均在 AMD Core Ryzen 7-3800X 3.9GHz CPU、32GB 内存环境下完成。在无特别说明时，牛顿迭代（算法~\ref{alg: nonlinear_solver}）的终止条件为
$\| \mathbf b + \nabla_{\mathbf{s}} \mathbf{C}_{\mathcal A}^\top \mathbf\lambda \|_{2} < \text{1e-5}$ 或达到 5 次迭代；实际中通常满足前者即终止。对于每个线性系统，PCG 在残差 $L_2$ 范数小于 1e-7 时停止。

\label{sec:cmp_res}
我们将本文方法与多种基线比较：罚函数法、笛卡尔坐标下直接 KKT 法、Super-Helices~\cite{bertails_super-helices_2006,bertails_linear_2009}，以及基于 RedMax~\cite{wang_redmax_2019} 的扩展方案。为量化约束违背，我们定义
$\frac{\sum_{i=0}^{n-2}\|\p_{i+1} - \p_i\|}{\sum_{i=1}^{n-1}l_i} - 1$
作为不可伸长约束误差，定义
$\sum_{i=0}^{n-2} \left\|\frac{\p_{i+1} - \p_i}{\|\p_{i+1} - \p_i\|} - d(\q_i) \right\|$
作为对齐约束误差。

\subsection{与罚函数方法的比较}
在罚函数法实验中，我们将能量 $E(\mathcal{T}(s))$ 替换为包含不可伸长与对齐罚项的 $E(\mathbf{x})$，并在图~\ref{fig:visual_damping_penalty} 场景中仿真。两罚项权重相同。每个时间步均求解关于 $E(\mathbf{x})$ 的无约束优化问题。

在第一组实验中，两方法均做 5 次牛顿迭代。图~\ref{fig:inext_penalty_a} 与图~\ref{fig:align_penalty} 表明，罚函数法难以在少量迭代下满足不可伸长与对齐约束，即精度不足；当权重偏小会出现明显拉伸，而权重增大又会在有限迭代下引入动力学伪影。

\subsection{与直接 KKT 方法的比较}
直接求解 KKT 系统虽无罚函数法的数值阻尼伪影，但计算代价高（图~\ref{fig:kkt_timing}），且在牛顿迭代不足时无法精确满足不可伸长与对齐约束（图~\ref{fig:kkt_violation_a}、图~\ref{fig:kkt_violation_b}）。相比之下，本文的紧凑表示在参数化层面满足~\cref{eq: inext_cons_d,eq: unitq_cons,eq: alignment_cons}。在相同的实验设置下，这避免了对内在约束进行额外计算迭代所需的开销。文献~\cite{deul_direct_2018} 亦包含 KKT 求解，但在每个牛顿步交替使用 KKT 与非线性 Gauss-Seidel，迭代不足时同样会出现约束违背。

\subsection{与 Super-Helices 的比较}
与我们的链式表示类似，Super-Helices~\cite{bertails_super-helices_2006} 通过缩减坐标同样可精确满足~\cref{eq: inext_cons_d,eq: unitq_cons,eq: alignment_cons}，并由~\cite{bertails_linear_2009} 提供线性时间求解器。不同之处在于，Super-Helices 采用高阶曲线单元，在平滑变形场景下可用更少自由度表示形状；但在复杂接触下其表达能力下降，需引入更多自由度。

此外，其方法并非如本文隐式时间步进般无条件稳定~\cite{bertails_linear_2009}：由于显式计算 $\ddot{\kappa}_{\mathcal{Q}}$，时间步上限会随单元数增多而明显降低——单曲线单元时最大约 $\SI{35}{ms}$，40 单元时仅约 $\SI{4}{ms}$。我们在其基准相似场景中（图~\ref{fig:compare_to_super_helix}）使用 200 个线段并取 $\SI{250}{ms}$ 时间步，仍能稳定仿真。

（$E = \SI{0.2}{MPa}, G = \SI{0.1}{MPa}, r = \SI{0.03}{m}, \rho = \SI{1}{\den}$，20 线段）中，我们得到与其相近结果但更高性能：其论文报告约 $\SI{54}{fps}$（时间步约 $\SI{8}{ms}$），而我们在 $\SI{30}{ms}$ 时间步下达到 $\SI{344}{fps}$。若仅按单线程 CPU 主频粗略归一化（其 $\SI{2.1}{GHz}$，我们 $\SI{3.9}{GHz}$），仍有约 $3.43$ 倍加速，且该对比尚未计入更大稳定时间步的收益。

\subsection{与 RedMax 的比较}
RedMax~\cite{wang_redmax_2019} 可高效模拟铰接刚体，也可扩展用于不可伸长杆。为公平比较，我们在\ref{model_redMax}节中将其扩展到 Kirchhoff 杆：通过球形关节描述旋转场沿杆变化。与 Super-Helices 类似，这会使雅可比与质量矩阵更复杂。另一个关键差别是，RedMax 先坐标变换后时间离散，而本文方法反之；因此 RedMax 忽略了更多隐式力项，稳定性更弱。

我们在图~\ref{fig:visual_damping_penalty} 相同场景下使用扩展 RedMax，并以二分法估计视觉稳定下的最大时间步。图~\ref{fig:timestep_limit} 显示：重力加速度越大，扩展 RedMax 越易失稳；本文方法可在更大时间步下稳定运行。

\subsection{更多结果}
除上述对比外，我们在更复杂场景展示方法能力。

\textbf{穿过弹簧的细杆。}
一根杆（$E = \SI{20}{MPa},G = \SI{20}{MPa}, r = \SI{0.03}{m}, \rho = \SI{0.1}{\den}$，30 线段）一端固定、另一端在滑槽中运动，并穿过两个弹簧（每个弹簧参数 $E = \SI{2}{MPa}, G = \SI{2}{MPa}, r = \SI{0.03}{m}, \rho = \SI{0.1}{\den}$，各 150 线段），如图~\ref{fig:demo_hang}。时间步 $\SI{0.003}{s}$ 下，每帧约 16 个碰撞接触，仿真速度约 $\SI{20}{fps}$。

\textbf{打结。}
如图~\ref{fig:demo_knot0}，在 $\SI{200}{N}$ 拉力下，结逐步收紧并承受中心线方向大张力。杆参数为
$E = \SI{20}{MPa}, G = \SI{20}{MPa}, r = \SI{0.03}{m}, \rho = \SI{0.1}{\den}$，100 线段。凭借紧凑表示，杆严格保持不可伸长；采用活动集的 SQP 在时间步 $\SI{0.003}{s}$ 下可达 $\SI{25}{fps}$。在最小结形成后继续将拉力增至 $\SI{20000}{N}$，可得到更紧结（图~\ref{fig:tightest_knot}）。

\textbf{超螺旋形成。}
我们模拟 Kirchhoff 杆（$E = \SI{1000}{MPa}, G = \SI{100000}{MPa}, r = \SI{0.003}{m}, \rho = \SI{200}{\den}$，50 线段）的超螺旋形成（图~\ref{fig:demo_plectoneme}），展示扭转能向弯曲能的转换。杆两端沿 $x$ 方向受拉（$\SI{1}{N}$）且仅允许沿 $x$ 方向自由移动；施加端部扭转速度 $\SI{10}{rad/s}$ 后，杆发生起皱并形成超螺旋。

\textbf{杆落在三个圆柱上。}
如图~\ref{fig:pulley}，参数为
$E = \SI{1}{MPa}, G = \SI{0.1}{MPa}, r = \SI{0.03}{m}, \rho = \SI{0.5}{\den}$、200 线段的杆落在三个圆柱上。由于本文方法数值阻尼较小，杆会先反弹一段时间后再稳定贴附。
