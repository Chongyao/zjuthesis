\section{软硬耦合分析}

本节聚焦于分析传统模态综合法在大规模特征值问题中的两类核心困难。一方面，单一划分与固定界面假设会限制局部基函数对全局低频柔顺响应的表达能力；另一方面，界面耦合过程中引入的舒尔补又会带来高昂的计算与存储负担。前者体现为表达层面的"软"失配，后者则体现为算法层面的"硬"代价。

\subsection{单一划分模态综合法表达缺陷分析}\label{sec:phase-complement}

为说明单一划分在表达层面的局限性，本节考虑定义在 $[0,L]$ 上的一维拉普拉斯特征问题。为简化讨论，此处忽略界面模态。
\begin{figure}[H]
  \centering
  \includegraphics[width=\linewidth]{frequency-vs-phase/basis.pdf}
  \includegraphics[width=\linewidth]{frequency-vs-phase/frequency-vs-phase.pdf}
  \caption[两组基函数的积分误差比较]{两组基函数的积分误差比较。本节比较了\Cref{eq:frequency-only}中的固定相位基（左上）和\Cref{eq:phase-complete-basis}中的相位完备基（右上）。下图显示，相位完备基的误差比固定相位基的误差小几个数量级（右下）。}
  \label{fig:integrated_error_comparison}
\end{figure}

对于定义在区间 $[a,b]$ 上的第 $i$ 个子结构（其中 $0 < a < b < L$），在 Dirichlet-Dirichlet 边界条件下的第 $j$ 个子结构特征模态为
\begin{equation}
  \begin{split}
  \tilde{\mathbf{S}}^p_{i,j} &= \sin\left(j\pi t\right), t\in[0,1], j=1,2,\cdots.
  \end{split}
\label{eq:frequency-only}
\end{equation}
其中 $t=(x-a)/(b-a)$。\Cref{fig:integrated_error_comparison}左上图展示了部分特征模态。\textcolor{ExplainConclusion}{此类特征模态在区间边界处的值均为零；即每个 $\sin(\omega t+\phi)$ 函数相对于区间的相位 $\phi$ 恒为零。因此，当 $\psi\neq k\pi$ 时，$t\in[0,1]$ 上形如 $\sin(j\pi t+\psi)$ 的函数在边界处存在非零值，这些基函数无法表示该类函数。单纯增加此类基函数的数量也无法解决该问题。}

从软硬耦合的角度看，这里的困难并不只是近似误差增大，而是固定界面这一算法假设直接改变了局部基函数的表达性质。子结构特征模态必须在边界处为零，这使得局部基函数天然带有受限的相位结构。对于真正的全局低频模态而言，即便局部基已经覆盖了足够高的频带，它们仍可能无法有效表达跨子结构延拓的柔顺响应。于是，算法不得不继续引入更多高频内部模态来弥补这一表达缺口，从而使降维效率迅速下降。

如果从力学角度理解这一现象，可以将其看作一种由算法假设诱发的“人工刚化”。真实的全局低频模态通常要求位移场能够平滑地跨越子结构边界延拓；而固定界面条件却强迫局部基函数在边界处取零，从而使原本应当平缓变化的响应在界面附近产生额外弯折。对于一维拉普拉斯问题，这种弯折直接体现为更高的梯度代价；对于更一般的弹性或结构动力学问题，则可理解为一种非物理的附加应变能。也就是说，固定界面并不是被动地“截断”了一部分低频响应，而是在逼近过程中主动改变了该响应的局部形状，使本来柔顺的全局模态在降维子空间中表现出偏硬的近似特征。

因此，这里的问题并不依赖于一维正弦函数这一特殊例子，而反映了单一划分局部基的一类普遍局限：当基函数的边界相位被预先锁定时，它们对跨子结构平滑传播的全局低频信息只能进行低效逼近。只要目标模态的主要特征包含明显的跨界面延拓，而局部基函数又被固定界面约束在某一类相位结构内，这种表达缺陷就会反复出现。换言之，单一划分下的问题并不只是“模态数不够”，而是降维基本身缺乏必要的相位自由度；只有重新组织局部基函数的相位结构，才有可能在不盲目增加内部模态数的前提下改善全局低频响应的表示质量。

\subsection{积分误差分析的实验细节}
\begin{figure}[tbp]
  \centering
  \includegraphics[width=\linewidth]{frequency-vs-phase/integration.pdf}
  \caption[完整域和积分子域]{完整域和积分子域。通过滑动区间起点 $a$ 自 $0$ 遍历到 $L-l$ 的方式，对子域 $[a, b]$ 积分处理，以破除针对性选择特定子域引发偏差的可能性。}
  \label{fig:integration}
\end{figure}

本节详细介绍了正文中用于对比频率适配基与相位适配基近似性能差异的数值实验方法。

\paragraph{实验目标}
本实验旨在提供一种稳健且与位置无关的局部基底近似效率评估方法。通过在整个域上滑动分析窗口（即子域）并对 $L_2$ 误差进行积分，该方法消除了单一固定划分可能带来的特定共振偏差，从而能够客观反映每种基函数的真实逼近性能。实验的具体设置如下：

\paragraph{全局问题}
目标函数选取定义在区间 $[0, L]$ 且满足 Dirichlet 边界条件的一维拉普拉斯全局特征模态，其表达式为 $f(x; n_{\text{global}}) = \sin(n_{\text{global}} \pi x / L)$。

\paragraph{滑动子域}
在区间 $[a, a+l]$ 上定义一个长度固定为 $l$ 的子域。通过使左端点 $a$ 从 $0$ 连续变化至 $L-l$，实现该子域窗口在全域上的滑动，如 \Cref{fig:integration} 所示。

\paragraph{基函数集合}
给定内部模态数 $M$，在区间 $[a, a+l]$ 上构造两组不同的基。两组基的总函数个数均为 $M+2$：
\begin{itemize}
    \item \textbf{频率适配基：} 包含 $M$ 个频率递增的正弦模态 $\{ \sin(m\pi(x-a)/l) \}_{m=1}^M$，以及 2 个线性界面（Lagrange）模态。
    \item \textbf{相位适配基：} 包含正弦与余弦混合的模态集合 $\{ \sin(m\pi(x-a)/l), \cos(m\pi(x-a)/l) \}_{m=1}^{\lfloor M/2 \rfloor}$；若 $M$ 为奇数，则额外添加一个正弦模态；此外同样包含 2 个线性界面模态。
\end{itemize}

\paragraph{误差计算}
对于每一个窗口位置 $a$，将目标函数投影到所选的基函数集合上，从而计算出 $L_2$ 近似误差 $E(a)$。正文热图中最终报告的度量指标为\textbf{积分平均误差} $\bar{E}$，其计算公式为：
\begin{equation}
\bar{E}(n_{\text{global}}, M) = \frac{1}{L-l} \int_{0}^{L-l} E(a; n_{\text{global}}, M) \, da.
\end{equation}

\paragraph{参数设置}
生成正文积分误差对比结果时使用的具体参数如下：
\begin{itemize}
    \item 全局域长度：$L = 10.0$
    \item 滑动子域长度：$l = 2.0$
    \item 测试的最高全局特征模态阶数：$n_{\text{global,max}} = 8$
    \item 测试的最大内部模态数：$M_{\text{max}} = 12$
\end{itemize}
所有的积分计算均调用 \texttt{scipy.integrate.quad} 函数进行高精度数值积分。
\subsection{界面约束模态的高频刚性分析}\label{sec:schur-complement}

在传统模态综合法中，子结构内部的低频特征模态主要用于描述子结构内部较平滑、较柔顺的低频变化；与之不同，界面约束模态并不是这一类内部振型的自然延拓，而是由界面自由度上的单位位移激励诱导出的一类局部响应。换言之，界面模态的构造起点并不是“全局低频结构本身如何变化”，而是“当界面上某一局部位移被强制施加时，子结构内部如何响应”。从表示角色上看，这类模态更接近一种边界驱动下的局部传递对象，而不是直接承载全局柔顺行为的主体基函数。

正因为其来源于局部化的界面激励，这类界面约束模态往往表现出更强的局域性。界面上的单位位移在空间上近似于一种高度集中的边界扰动，相应诱导出的子结构响应也会在界面附近形成更明显的局部梯度与应变集中。若从谱与表示的角度理解，这意味着它们在性质上更偏向于“硬”的一侧：它们所携带的不是平滑延拓的低频主体信息，而是为了维持局部界面耦合而引入的一类高梯度、强局域的约束响应。对于目标为全局低频模态的分析而言，这些界面成分并非毫无必要，但它们与真正希望保留的柔顺低频结构并不处在同一类表示层次之上。

因此，传统模态综合法在界面层面面临的困难，并不是单纯"界面模态数量太多"，而是其耦合机制本身在表示结构上引入了另一类偏硬的局域对象。最终希望恢复的是跨子结构平滑传播的全局低频响应，但传统方法为了完成界面耦合，往往先构造出大量局部化的界面约束模态，再将这些成分装配并重新压缩到降维系统中。由此，降维子空间内部实际上同时包含两类性质差异明显的基函数：一类试图表达全局低频柔顺响应的内部模态，另一类是承担局域耦合的界面约束模态。前者偏"软"，后者偏"硬"，二者在表示层次上的不协调，构成了传统单划分模态综合法中的另一种软硬失配。若要真正缓解这一问题，更合理的方向并不是继续压缩这类局部高频界面模态，而是从基函数构造层面重新审视界面耦合方式，尽量避免将界面表示建立在大量高度局域、梯度尖锐的约束响应之上，使界面耦合所引入的基函数更贴近目标低频响应的整体结构。
