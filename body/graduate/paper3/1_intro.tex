前两章分别讨论了由显式几何约束和局部离散畸变引起的软硬耦合问题，并说明通过重构表示空间可以消除或隔离不良数值刚度。然而，当问题规模扩展至千万乃至上亿自由度的结构动力学与模态分析时，计算瓶颈转向了如何高效构造既能表达全局低频响应、又保持良好并行扩展性的降维特征子空间。即使网格质量良好，传统大规模降维框架中的空间划分与界面处理机制仍可能人为引入附加刚度，进而造成低频响应表达不足。这正是本章讨论的第三类软硬耦合问题：由算法构造导致的降维特征空间失衡。

\section{引言}

大规模工程结构的模态分析，本质上是从高维广义特征值问题 $\mathbf{K}\mathbf{u}=\lambda\mathbf{M}\mathbf{u}$ 中提取主导系统宏观动态行为的低频模态。在航空航天装备、复杂装配体和大规模图形学模型中，待分析系统往往包含千万甚至上亿自由度。尽管整体式求解器能够提供高精度结果，但其在迭代过程中需要反复执行超大规模线性求解与预处理操作，计算与存储代价都十分高昂，也不利于支持频繁的局部设计修改与重复分析。

为缓解这一瓶颈，工业界长期采用模态综合法（Component Mode Synthesis, CMS）等区域分解降维技术，通过对子结构进行独立求解来提升并行性与可复用性。然而，经典 CMS 在固定界面约束下提取子结构模态时，会人为切断跨子域的低频响应，导致局部模态难以充分表达真实的全局柔顺行为。为了弥补这一缺失，传统方法往往不得不引入更多内部模态与昂贵的界面缩减操作，从而在效率、精度与可扩展性之间形成新的张力。

\subsection{相关工作}

大规模工程结构低频模态分析是一个典型的特征值问题。标准整体式方法将特征求解器直接应用于完整、未划分的系统矩阵。典型求解器包括 Krylov 子空间方法（如 Lanczos 或 Arnoldi 方法）\cite{Hernandez2005SLEPc, Qiu2015Spectra}、Jacobi-Davidson 方法\cite{Sleijpen2000JD}以及局部最优块预处理共轭梯度法（LOBPCG）\cite{knyazev2001lobpcg}。这类方法精度高、通用性强，但随着模型规模增加，其内存消耗和重复线性求解的成本会迅速上升。

\subsubsection{模态综合法}

上述计算瓶颈推动了基于区域分解的降维技术发展，其中最具代表性的是模态综合法（CMS）\cite{seshu1997substructuring, William1985CMS, bourquin1992component}。具有里程碑意义的 Craig-Bampton 方法\cite{craig1968coupling} 通过固定界面正规模态与静态约束模态构造缩减基，并已被广泛应用于商业有限元软件\cite{Vysok2017CurrentCO}。然而，对于现代高保真有限元模型，随着子结构特征模态数量与界面自由度规模的增加，经典 CMS 很快面临严重的扩展性瓶颈\cite{KRATTIGER2019Riview}。

为缓解上述问题，研究者提出了多种改进策略。界面模态缩减法（Interface Mode Reduction, IMR）旨在直接缩减界面问题的规模 \cite{Kuether2017InterfaceReduction}；自动化多级子结构法（Automated Multi-Level Substructuring, AMLS）等层次化方法则将分解过程递归应用 \cite{Bennighof2004AMLS, Boo2016ErrorEstimation, Papalukopoulos2006Dynamics}。其他方法如近似模态综合法（Approximate Component Mode Synthesis, ACMS），通过多尺度或调和函数重新构造基底 \cite{hetmaniuk2010special, hetmaniuk2014error, Heinlein2015ACMS, Madureira2025SACMS, giammatteo2024extension}。

此外，在传统的 CMS 以及现有的界面模态缩减法中，处理连接各子结构的界面模态往往是一项计算瓶颈。为了获得准确的界面低频响应，通常需要计算界面系统或局部界面的 Schur 补，并求解稠密的特征值问题。\textcolor{IsConclusion}{这些稠密矩阵的组装与存储不仅内存消耗巨大，而且随界面自由度的增加呈现平方级增长，其通信开销也严重制约了分布式并行效率。}
\subsubsection{界面模态缩减法}

\subsubsection{界面模态缩减法}

由于界面系统通常规模庞大且矩阵稠密，研究者提出了多种面向界面的进一步缩减策略。\citet{Castanier20101Characteristic} 在界面全局组装后直接求解凝聚系统的特征值问题，这类方法可视为系统级缩减。对于可分离的简单界面，也有工作在独立界面及其相邻子结构上局部计算 Schur 补并进行界面压缩\citep{Cheon2023Enhanced,KRATTIGER2019Riview}；当界面结构更复杂时，则可对子结构级别的凝聚界面矩阵进行特征分解\cite{HONG2013403, Kuether2017Model}。此外，\citet{BATTIATO2018187} 还提出了适用于非协调网格的 Gram-Schmidt 界面模态方法。

\subsubsection{划分与区域分解法}

与区域分解法（Domain Decomposition Method, DDM）\cite{Smith1997DDM} 类似，CMS 依赖对子域的合理划分。现有工作采用了多种划分策略，包括基于空间坐标的几何划分、利用主成分分析（PCA）进行顶点聚类\cite{HUANG2006927}，以及基于图划分的 METIS\cite{Karypis1995graph, Karypis1997METIS} 和 CHACO\cite{Hendrickson2011} 等方法。重叠区域分解法（如 Schwarz 方法）及其谱富集变体 GenEO\cite{M2AN_2005__39_4_693_0, Marco2024Overlap, NicoleSpillaneSolve2013,Ryadh2015Schwarz,Spillane2025GenEO} 在线性系统求解中表现出良好的并行性能；图形学领域也已有并行加性 Schwarz 方法用于加速变形体仿真\cite{Wu:2022:GBM}。然而，这类工作主要聚焦线性系统求解，而非大规模全局特征值问题。本文并不把重点放在划分优化本身，而是关注如何在给定划分下重构更适合表达全局低频响应的降维空间。

\subsubsection{奇异矩阵束}

奇异矩阵束（Singular matrix pencil）问题，即矩阵束 $\mathbf{K} - \lambda \mathbf{M}$ 对所有 $\lambda$ 均满足 $\DET{\mathbf{K} - \lambda \mathbf{M}} = 0$ 的情况，也是大规模计算中常见的挑战。这通常发生在刚度矩阵 $\mathbf{K}$ 与质量矩阵 $\mathbf{M}$ 共享相同的零空间时。Kronecker 典范型（Kronecker Canonical Form, KCF）\cite{gantmakher2000theory, Van1979Kronecker, Berger2012QuasiKroneckerFrom} 表明，此类矩阵束可分解为正则部分与奇异部分。其中，奇异部分具有病态特征，极易导致数值不稳定：矩阵元素的微小扰动便可能引起计算所得谱发生极大且不连续的变化\cite{Hochstenbach2019SolvingSingular, Kressner2024AnalysisOfeigenvalue}。

处理奇异矩阵束的核心思想是“提取”并隔离其奇异结构。直接方法的基础是阶梯算法（staircase algorithm）\cite{Demmel1993TheGS, Van1979Kronecker}，例如被广泛采用的 GUPTRI 实现\cite{Demmel1993TheGS}。尽管这些直接方法在理论上完备，但存在两个严重缺陷：第一，反复进行奇异值分解（SVD）导致了高达 $\mathcal{O}(n^3)$ 的计算复杂度；第二，在有限精度算术中，算法依赖数值病态的秩判定，而判定误差可能破坏后续整个计算流程\cite{Edelman2000StaircaseFailures}。为应对此问题，一些研究对 Lanczos 或 Arnoldi 等传统迭代方法进行了修改\cite{Lin2021ShiftInvertLanczos, karl2024ShiftInvertArnoldi}。此外，正则化方法尝试将奇异矩阵束摄动为邻近、适定的正则矩阵束\cite{Fernando2008FirstOrder, Hochstenbach2019SolvingSingular}，但这类方法通常仍需要执行高代价的秩判定步骤来指导摄动过程。

\subsection{本章方法与贡献}

本章的核心观察是：传统 CMS 的主要困难并不只在于模态数量不足，而在于固定界面划分本身破坏了跨子域低频响应的相位连续性。为此，本章不再沿着单一划分下补充更多高频局部模态的思路修补，而是直接重构降维特征空间的生成机制。具体而言，本文引入交错划分策略。不同划分在空间上的交错布置，使得某一组划分中的刚性界面，在另一组划分中往往落入相对平滑的内部区域。借助这种位置互补关系，不同划分下提取的局部低频模态能够在重叠区域内相互补充，从而更完整地逼近全局低频响应。

在此基础上，本文进一步提出了一种无 Schur 补和特征求解的 IMR 构造方法。该方法不再显式组装稠密 Schur 补，也不再重复执行高代价的局部界面特征分解，而是将一套划分上的界面模态求解转化为另一套划分子结构上的静力平衡问题，其边界条件直接从另一套划分已有的局部特征模态中提取。整体而言，本文的贡献主要包括：
\begin{itemize}
\item 提出了一种基于交错划分的特征空间重构框架，通过不同划分之间的相位补足机制，提升了大规模系统低频模态的表达能力。
\item 提出了一种无 Schur 补和特征求解的 IMR 近似方法，用以替代传统界面缩减流程中的高代价边界处理步骤。
\item 通过大规模数值实验验证了该方法在低频特征提取精度、并行扩展性以及局部模型修改后重分析效率方面的综合优势。
\end{itemize}
