前两章分别讨论了由物理本构与空间离散诱发的软硬耦合问题，并表明通过重构表示空间可以有效隔离局部高频刚度。然而，当问题规模扩展至千万乃至上亿自由度的结构动力学与模态分析时，限制计算效率的关键矛盾不再仅仅来自局部畸变单元或显式几何约束，而转向了如何高效构造能够表达全局低频响应的降维特征子空间。即使系统网格本身质量良好，传统大规模降维框架中的空间划分与界面处理机制仍可能人为引入附加刚度，进而造成低频响应表达不足。这正是本章讨论的第三类软硬耦合问题：由算法构造导致的降维特征空间失衡。

\section{引言}

大规模工程结构的模态分析，本质上是从高维广义特征值问题 $\mathbf{K}\mathbf{u}=\lambda\mathbf{M}\mathbf{u}$ 中提取能够主导系统宏观动态行为的低频模态。在航空航天装备、复杂装配体和大规模图形学模型中，待分析系统往往包含千万甚至上亿自由度。尽管整体式求解器能够提供高精度结果，但其在迭代过程中需要反复执行超大规模线性求解与预处理操作，计算与存储代价都十分高昂，也不利于支持频繁的局部设计修改与重复分析。

为缓解这一瓶颈，工业界长期采用模态综合法（Component Mode Synthesis, CMS）等区域分解降维技术，通过对子结构进行独立求解来提升并行性与可复用性。然而，经典 CMS 在固定界面约束下提取子结构模态时，会人为切断跨子域的低频响应，导致局部模态难以充分表达真实的全局柔顺行为。为了弥补这一缺失，传统方法往往不得不引入更多内部模态与昂贵的界面缩减操作，从而在效率、精度与可扩展性之间形成新的张力。

\subsection{相关工作}

大规模工程结构低频模态的模态分析是一个典型的特征值问题。标准的整体式方法将特征求解器直接应用于完整的未分区系统矩阵。典型的求解器包括 Krylov 子空间方法（如 Lanczos 或 Arnoldi 方法）\cite{Hernandez2005SLEPc, Qiu2015Spectra}、Jacobi-Davidson 方法\cite{Sleijpen2000JD}以及局部最优块预处理共轭梯度法（LOBPCG）\cite{knyazev2001lobpcg}。这类方法具有较高的精度与通用性，但随着模型规模增加，其内存消耗和重复线性求解的成本会迅速上升。

\subsubsection{模态综合法}

上述计算瓶颈推动了基于区域分解的降维技术发展，其中最具代表性的是模态综合法（CMS）\cite{seshu1997substructuring, William1985CMS, bourquin1992component}。具有里程碑意义的 Craig-Bampton 方法\cite{craig1968coupling} 通过固定界面正规模态与静态约束模态构造缩减基，并已被广泛应用于商业有限元软件\cite{Vysok2017CurrentCO}。然而，对于现代高保真有限元模型，随着子结构特征模态数量与界面自由度规模的增加，经典 CMS 很快面临严重的扩展性瓶颈\cite{KRATTIGER2019Riview}。

\subsubsection{界面模态缩减法}

由于界面系统通常规模庞大且矩阵稠密，研究者提出了多种面向界面的进一步缩减策略。\citet{Castanier20101Characteristic} 在界面全局组装后直接求解凝聚系统的特征值问题，这类方法可视为系统级缩减。对于可分离的简单界面，也有工作在独立界面及其相邻子结构上局部计算 Schur 补并进行界面压缩\citep{Cheon2023Enhanced,KRATTIGER2019Riview}；当界面结构更复杂时，则可对子结构级别的凝聚界面矩阵进行特征分解\cite{HONG2013403, Kuether2017Model}。此外，\citet{BATTIATO2018187} 还提出了适用于非协调网格的 Gram-Schmidt 界面模态方法。

\subsubsection{划分与区域分解法}

与区域分解法（DDM）~\cite{Smith1997DDM}类似，CMS 依赖对子域的合理划分。现有工作采用了多种划分策略，包括基于空间坐标的几何划分、利用主成分分析（PCA）进行顶点聚类~\cite{HUANG2006927}，以及基于图划分的 METIS~\cite{Karypis1995graph, Karypis1997METIS} 和 CHACO~\cite{Hendrickson2011} 等方法。本文并不把重点放在划分优化本身，而是关注如何在给定划分下重构更适合表达全局低频响应的降维空间。

\subsection{本章方法与贡献}

本章的核心观察是：传统 CMS 的主要困难并不只在于“模态数量不足”，而在于固定界面划分本身破坏了跨子域低频响应的相位连续性。为此，本章不再沿着单一划分下补充更多高频局部模态的思路修修补补，而是直接重构降维特征空间的生成机制。

具体而言，本文引入了多重错位划分策略。不同划分在空间上的交错布置，使得某一组划分中的刚性界面，在另一组划分中往往落入相对平滑的内部区域。借助这种位置错位带来的互补性，不同划分下提取的局部低频模态可以在重叠区域内相互补充，从而更完整地逼近全局低频响应。

在此基础上，本文进一步提出了无需显式构造稠密 Schur 补、也无需重复执行高代价局部界面特征求解的 IMR 近似公式，以降低传统界面缩减步骤的计算与存储负担。整体而言，本文的贡献主要包括：
\begin{itemize}
\item 提出了一种基于错位多重划分的特征空间重构框架，通过不同划分之间的相位互补机制，提升了大规模系统低频模态的表达能力。
\item 提出了一种无需显式组装和求解稠密 Schur 补的 IMR 近似公式，用以替代传统界面缩减流程中的高代价边界处理步骤。
\item 通过大规模数值实验验证了该方法在低频特征提取精度、并行扩展性以及局部模型修改后的重分析效率方面的综合优势。
\end{itemize}
