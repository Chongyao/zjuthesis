【1. 课题来源】

本课题来源于计算机图形学与计算物理仿真领域的前沿研究需求，受到国家自然科学基金
和浙江大学研究生科研创新项目的支持。

物理模拟的系统性探索可追溯至20世纪中叶。伴随着有限元方法（Finite Element Method, 
FEM）在航空航天与结构工程中的萌芽，人类开始尝试利用严谨的数学工具描述宏观世界
的动态演变。进入20世纪80年代末至90年代，物理模拟迎来了一个飞速发展的黄金阶段。
这一过程并非单一领域的线性演进，而是两条各具特色、互为补充的技术路径并行驱动的
结果。

一方面，计算机辅助工程（Computer-Aided Engineering, CAE）领域在这一时期确立了
其在工业设计中的核心地位。CAE致力于通过高精度的数值方法还原物理规律，以实现对
结构强度、流体动力等关键指标的可靠预测。与之并行的，是计算机图形学（Computer 
Graphics, CG）发生的深刻变革：研究者们意识到，传统的几何建模已难以满足日益增长
的视觉表现需求，模拟的真实感必须植根于底层的物理机制。

在现代计算图形学与计算物理仿真中，弹性体及复杂结构的动力学计算面临着一个极为
普遍且艰巨的挑战："软硬耦合"（Stiff-soft Coupling）问题。物理系统在不同尺度或
不同组件之间往往展现出截然不同的刚度响应。例如，在一维细长杆件中，沿着轴向的
拉伸刚度（无穷大硬约束）与横向的弯曲扭转刚度（极软）交织在一起；在三维连续体的
有限元（FEM）分析中，局部发生几何畸变（如Sliver Elements）的网格会因为极其糟糕
的单元条件数而产生巨大的人工数值刚化（Locking），与周围正常的柔软组织形成剧烈
冲突；而在宏观尺度的复杂机械装备或大尺度结构动力学分析中，不同子结构交界面处的
高频强耦合与子结构内部的低频柔性形变同样构成典型的软硬耦合现象。

在传统的全自由度笛卡尔坐标系或标准节点有限元基底下直接求解这些软硬耦合系统，
往往会带来灾难性的数值后果。强行引入隐式拉格朗日乘子或高数值的惩罚弹簧，不仅会
导致系统全局刚度矩阵的条件数（Condition Number）急剧爆炸，使得线性求解器陷入
停滞，还会极大程度地限制时间积分的步长，使得高保真仿真的计算代价变得无法承受。

本课题旨在通过定制化的基函数与坐标变换方法，在不牺牲物理精确度的前提下突破这一
计算瓶颈。本研究的核心思想是通过基底的变换重构，将棘手的结构性病态转化为易于
处理的尺度问题，或直接在降维子空间中规避刚性维度的计算。

【2. 课题的研究意义】

（一）面向世界科技前沿

从计算机科学的视角来看，物理模拟的进步实质上是计算几何、数值分析、高性能计算
（HPC）与数据结构等核心领域的综合交叉产物。这种多学科的交织使得研究者能够在有限
的算力约束下，通过算法创新处理从微观粒子到宏观天体的跨尺度仿真任务。

迈入21世纪20年代，物理模拟的研究立意进一步升华。在具身智能（Embodied AI）与
世界模型（World Models）蓬勃发展的今天，高保真的仿真环境已成为智能体理解物理
法则、实现虚实迁移（Sim-to-Real）的关键"数字实验室"。值得注意的是，这一新范式
对仿真算法提出了前所未有的鲁棒性要求：智能体的学习过程涉及数以万计的闭环迭代，
任何微小的数值不稳定性都可能导致训练失败或物理逻辑谬误。因此，攻克物理仿真中的
数值瓶颈，已从单纯的视觉追求演变为构建通用人工智能（AGI）底座的核心技术诉求。

物理仿真是计算机图形学、计算力学、机器人学等领域的核心技术，代表着世界科技前沿
的发展方向。本研究提出的基函数重构方法，为构建更健壮、更高效的物理仿真系统提供
了新的理论范式，对推动计算机科学在物理仿真领域的创新具有重要意义。研究成果有望
在顶级国际学术会议和期刊（如SIGGRAPH、TOG、TVCG等）发表，提升我国在该领域的
国际学术影响力。

（二）面向国家重大需求

我国在航空航天、汽车工业、智能制造等领域对高精度物理仿真有迫切需求。传统仿真
方法在处理复杂耦合系统时存在数值稳定性不足、计算效率低下等问题，严重制约了
国产CAE软件的发展。目前，国际主流的CAE软件（如ANSYS、Abaqus、Nastran等）主要
被欧美企业垄断，我国在自主可控CAE软件方面存在明显短板。

本研究提出的基函数重构方法可有效提升仿真系统的鲁棒性和计算效率，为我国自主CAE
软件的研发提供技术支撑。具体体现在以下几个方面：

1. 提升数值稳定性：通过基函数重构消除系统的结构性病态，显著改善求解器的收敛
   特性，减少数值发散和计算失败的情况。

2. 加速计算效率：近线性复杂度的求解算法可大幅缩短仿真计算时间，提高工程设计的
   效率，缩短产品研发周期。

3. 支持大规模并行：方法天然支持分布式并行计算，可充分利用国产高性能计算资源，
   处理超大规模仿真问题。

4. 促进软件自主可控：为国产CAE软件的数值核心模块提供关键技术，减少对国外软件
   的依赖，增强产业链安全。

（三）面向经济主战场

物理仿真技术广泛应用于工业产品设计、虚拟现实、数字孪生、影视特效、游戏开发等
产业。据统计，全球CAE软件市场规模已超过80亿美元，年增长率保持在10%以上。在
我国"十四五"规划和"中国制造2025"战略中，工业软件被列为重点发展领域。

本研究成果可显著提升仿真计算的效率和稳定性，降低产品研发周期和成本，增强相关
产业的技术竞争力，服务国民经济发展。具体应用领域包括：

1. 汽车工业：车辆碰撞仿真、NVH分析、疲劳寿命预测
2. 航空航天：飞行器气动弹性分析、结构动力学仿真
3. 电子行业：电子产品跌落仿真、热力耦合分析
4. 文化创意：影视特效、虚拟现实游戏、数字人动画
5. 医疗健康：手术仿真、康复器械设计、生物力学分析

（四）面向人民生命健康

在医疗仿真、手术规划、康复工程等领域，高保真物理仿真正发挥越来越重要的作用。
本研究提出的鲁棒仿真方法可为医疗仿真提供更稳定、更高效的数值工具，助力精准
医疗和健康产业发展。

具体应用场景包括：

1. 手术规划：通过术前仿真预测手术效果，制定最优手术方案
2. 康复工程：假肢和康复器械的生物力学仿真优化
3. 药物输送：血管内药物输送的流体动力学仿真
4. 医学教育：虚拟手术培训系统，提高医学教育质量

【3. 国内外研究现状分析】

（一）弹性体仿真方法研究现状

弹性体仿真是计算机图形学和计算力学的核心问题，其研究历程可追溯至20世纪中叶。
根据离散化策略的不同，主要方法可分为以下几类：

1. 质点-弹簧模型（Mass-Spring Model）
质点-弹簧模型是最早的弹性体仿真方法之一，其优点是计算简单、易于实现，适用于
实时交互应用。然而，该方法的材料参数难以与真实物理属性对应，精度有限，难以
准确模拟真实弹性体的行为。代表性工作包括Selle等人（2008）提出的大规模质点-
弹簧系统。

2. 有限元方法（Finite Element Method, FEM）
有限元方法是目前工程应用最广泛的数值方法，具有坚实的数学理论基础和高精度特点。
Hughes（2012）在《The Finite Element Method》中系统阐述了FEM的理论框架。FEM
的核心思想是将连续体离散为有限个单元，通过插值函数建立单元内部的位移场，进而
推导系统的刚度矩阵和质量矩阵。然而，传统FEM在处理大变形、网格畸变等问题时
面临数值锁死（Locking）和网格依赖性等挑战。

3. 边界元方法（Boundary Element Method, BEM）
边界元方法只需在边界上离散，内部无需划分网格，特别适合无限域问题和裂纹问题。
但BEM产生的矩阵是稠密的，存储和求解代价较高，且对非均匀材料处理困难。

4. 离散元素法（Discrete Element Method, DEM）
离散元素法将连续体离散为大量离散粒子的集合，每个粒子具有独立的质量和运动状态。
该方法适合颗粒材料、岩土工程等应用，但对连续弹性体的模拟精度有限。

5. 无网格方法（Meshless Methods）
无网格方法如光滑粒子流体动力学（SPH）、物质点法（MPM）等，避免了网格划分的
困扰，适合处理大变形和断裂问题。但无网格方法的边界条件处理和数值积分精度仍
存在挑战。

近年来，研究者们提出了多种加速和稳定化技术，包括模型降维方法（Model Reduction）、
自适应网格细化（Adaptive Mesh Refinement）、预处理器优化（Preconditioning）和
并行计算技术（Parallel Computing）。

（二）细长杆仿真方法研究现状

细长弹性结构（如毛发、绳索、缝合线等）的仿真是一个具有挑战性的问题。代表性
方法包括：

1. 传统节点表示方法
Spillmann等人（2007, 2008, 2020）通过中心线上顶点的笛卡尔坐标表示杆的形状，
用单元四元数表示材料标架。这种方法简单直观，但需要处理长度约束、四元数单位化
约束和轴对齐约束等大量约束条件。

2. Bishop标架方法
Bergou等人（2008, 2010）提出通过沿中心线平行移动计算无扭转标架（Bishop框架），
将材料标架表示为与Bishop框架的差值（扭转角）。这种表示消除了四元数和对齐约束，
但单元上的伸长仍作为自由度保留。

3. Super-Helices方法
Bertails等人（2006）提出了一种恰好匹配不可伸长Cosserat杆内蕴自由度的表示方法，
将杆离散化为不可伸长单元，每个单元的材料曲率和扭转为常数。该方法精度高，但
积分过程产生稠密质量矩阵，算法复杂度为O(N²)。Bertails（2009）将复杂度降至线性，
但仍存在大时间步长下的稳定性问题。

4. RedMax方法
Wang等人（2019）提出了铰接刚体链的递归表示方法，使用块对角预处理器实现高效
求解器。该方法适用于实时应用，但对碰撞等交互的处理仍有局限。

（三）病态问题与条件数优化研究现状

系统病态性（Ill-conditioning）是数值仿真的核心难题，源于矩阵条件数的极端值。
条件数定义为矩阵最大与最小特征值之比：κ(A) = |λ_max| / |λ_min|。当条件数
过大时，求解器的收敛速度大幅下降，甚至因舍入误差累积而无法获得可靠解。

现有解决方案主要包括：

1. 预处理器设计
- 不完全LU分解（ILU）：保持稀疏性的近似分解
- 多重网格方法（Multigrid）：利用多尺度信息加速收敛
- 区域分解预处理器：适合并行计算

然而，传统预处理器多为"黑盒"式代数修补，未从根本上解决离散表达与物理本质的
失配问题。

2. 正则化方法
- Tikhonov正则化：在病态矩阵中添加正则化项
- 截断奇异值分解（TSVD）：截断小奇异值改善条件数

正则化方法在改善条件数的同时可能损失物理精度。

3. 基函数优化
- 谱方法：使用正交多项式作为基函数
- 小波方法：多分辨率分析
- 自适应基函数：根据问题特性调整基函数

这些方法提供了改善系统病态性的新思路，但针对软硬耦合问题的专门研究仍较为有限。

（四）模态综合法（CMS）研究现状

模态综合法是解决大规模特征值问题的有效方法，起源于航空航天领域。代表性工作包括：

1. Craig-Bampton方法
Craig和Bampton（1968）提出了固定界面模态综合法，将子结构特征模态和界面模态
组合构成缩减基。该方法几乎被应用于所有商业有限元软件（MSC Nastran、ANSYS、
Abaqus等）。

2. Craig-Chang方法
Craig和Chang提出了自由界面模态综合法，适用于某些特定的界面配置。

3. 界面模态缩减法（IMR）
Kuether等人（2017）提出通过在Schur补步骤后求解局部特征问题，仅计算低频界面
模态以降低计算成本。但该方法仍需执行昂贵的Schur补计算。

4. 自动多层次子结构法（AMLS）
Bennighof等人（2004）提出了递归应用分解的AMLS方法，实现了高效的层次化求解。

现有CMS方法的主要瓶颈：
（1）子结构基底无法有效张成目标解空间，收敛速度往往不尽如人意
（2）Schur补计算代价高昂且内存密集
（3）随着子结构特征模态数量增加，误差下降缓慢

（五）本研究的切入点与创新点

针对上述问题，本研究提出"基函数重构"的新范式，核心创新在于：

1. 理论创新：从离散表达层面解决软硬耦合问题，区别于传统的代数预处理器方法

2. 方法创新：
- 紧凑坐标表示：通过坐标变换消除内在约束，将约束优化转化为无约束优化
- 相位互补模态基：利用多重划分实现基函数相位完备，提升收敛速度
- 算子自适应基函数：识别并过滤高频伪刚性模式，改善系统病态性

3. 应用创新：方法可广泛应用于毛发动画、模态分析、有限元仿真等领域

二、研究方案
===============================================================================

【1. 研究目标、内容和拟解决的关键问题】

（一）研究目标

建立一套基于基函数重构的软硬耦合问题求解理论框架，实现高效、鲁棒的物理仿真。
具体目标包括：

1. 建立基函数重构的统一理论框架，阐明其与传统方法的本质区别
2. 发展针对不同类型软硬耦合问题的专用基函数设计方法
3. 实现近线性复杂度的高效求解算法
4. 验证方法在典型应用场景中的有效性和实用性

（二）研究内容

本研究的核心思想是通过定制化的基函数与坐标变换，在新的表示子空间内"吸收"或
"剥离"系统的硬约束与病态特征。具体而言，与其在极度病态的原始物理节点空间中
求解，不如将物理系统映射到一个能够自然兼容硬约束或过滤高频伪模式的全新基底中。

研究内容一：不可拉伸弹性棒仿真（一维极度耦合）

对于一维细长弹性结构（如毛发、绳索、缝合线等），其核心的软硬耦合体现在长度的
绝对"不可伸长性"（无穷大拉伸刚度）与极小的弯曲/扭转刚度之间的矛盾。在传统的
有限元或基于节点的表示方法中，为了描述Cosserat杆的空间位姿，往往需要保留冗余
的节点坐标和姿态四元数，并通过海量的几何非线性方程来硬性约束其长度和相邻节点
的对齐关系，这使得约束非线性优化问题极其僵硬和难以求解。

本研究提出了一种紧凑坐标表示（Compact Representation）方法。通过一次深度的
坐标基变换，摒弃传统的节点位置自由度，转而使用基于根节点位置以及局部轴角
（Axis-angle）的曲率链式参数化体系。在这一全新的坐标基底下，系统的求解维度被
精确缩减至与其内蕴自由度完全一致的3n维。更重要的是，这种基函数变换在表示层面
上天然地满足了不可伸长、四元数单位化以及局部对齐等所有硬约束，从而将一个条件
极其恶劣的带约束优化问题，完美转换为了无约束的软体优化问题。

研究内容二：大规模特征值问题求解（宏观全局耦合）

在超大规模弹性系统（如大型机械部件的特征值分析或模态提取）中，系统的宏观低频
柔性运动通常与各子结构界面处高频、强刚度的耦合约束交织在一起。传统的全局刚度
矩阵由于维度极高，计算其极小特征对极为困难；而标准的模态综合法（CMS）虽然通过
降维极大地缓解了计算压力，但其对界面约束模态的求解（即计算Schur补）在面对
海量界面节点时依然极其昂贵，且容易引发精度流失。

本研究在CMS理论基础上，创新性地提出了一种基于多重划分（Primal-Dual）的相位
互补模态基变换方法。将庞大的全节点物理空间映射至由不同空间划分策略提取出的
降维模态子空间中。由于不同的划分方式在界面和内部节点处具有不同的频谱捕捉特性，
这种多重基函数空间能够形成完美的"相位互补"。基于此，提出了无Schur补及无局部
特征求解的界面模态缩减法（SE-free IMR），直接利用对偶划分中的低频模态基去
近乎无损地逼近原始的界面约束空间。

研究内容三：畸变单元稳定性处理（三维局部畸变）

在三维弹性体有限元分析中，病态网格单元（特别是包含两个极度靠近顶点的Sliver 
Elements）会产生极大的插值误差，并导致该区域的人工刚度急剧增加，这在原本柔软
的连续体中引入了严重的局部结构性病态，往往会导致预条件共轭梯度（PCG）等迭代
求解器彻底停滞。

本研究首先提出了谱几何退化分析，将系统的病态条件明确划分为可通过简单预处理器
缓解的"尺度病态"与由几何畸变主导的"结构性病态"。为了消除这种结构性硬耦合，
提出了一种数值感知（Numeric-aware）的局部细化与聚合策略。不再使用标准的FEM
节点插值多项式，而是利用局部刚度矩阵的主特征向量作为物理探针，识别出产生最强
人工锁定的方向。沿着这一方向，采用基于算子自适应的基函数优化与凝聚技术，重新
构造能够使得局部区域能量最小化的新插值基。

（三）拟解决的关键问题

1. 如何通过坐标变换消除不可拉伸弹性棒的内在约束？
   挑战：需要在保持物理精度的同时，将约束优化问题转化为无约束问题
   解决思路：设计紧凑坐标表示，使约束在表示层面自动满足

2. 如何构造相位完备的模态基函数提升CMS收敛速度？
   挑战：传统CMS子结构基函数相位固定，无法有效张成目标解空间
   解决思路：利用多重划分生成相位互补的基函数集合

3. 如何识别并过滤畸变单元产生的高频伪刚性模式？
   挑战：传统网格细化方法代价高昂且可能引入新的畸变
   解决思路：通过谱分析识别病态方向，设计自适应基函数过滤

4. 如何实现近线性复杂度的高效求解？
   挑战：大规模稀疏系统求解通常具有超线性复杂度
   解决思路：利用特殊矩阵结构设计高效预处理器

【3. 研究的创新点】

（一）理论创新

1. 提出"基函数重构"的新范式
区别于传统的代数预处理器方法，本研究从离散表达层面解决软硬耦合问题。核心
思想是通过重新设计离散空间的基函数，在投影层面实现软硬成分的数值解耦。这
一范式将"求解器优化"提升到"表达优化"的更高层次。

2. 建立统一的理论框架
三个研究内容（不可拉伸弹性棒、广义特征值问题、畸变单元）看似独立，实则共享
统一的理论内核：通过基函数变换，将结构性病态转化为尺度病态或直接消除。本
研究将首次建立这一统一的理论框架。

3. 揭示相位完备性的数学本质
在模态综合法研究中，首次明确指出传统CMS收敛慢的根本原因——基函数相位固定。
通过多重划分实现相位完备，为CMS理论提供了新的视角。

（二）方法创新

1. 紧凑坐标表示方法
- 将约束优化问题转化为无约束问题
- 系统维度从7n-4降至3n，与内蕴自由度精确匹配
- 所有内在约束在表示层面自然满足

2. 近线性复杂度预处理器
- 利用系统矩阵的特殊结构（块三对角）
- 构造对称正定的混合预处理器
- PCG收敛速度提升1-2个数量级

3. 相位互补的多重划分策略
- 利用Primal-Dual空间交错划分
- 生成相位完备的模态基函数
- 精度提升3个数量级

4. 无Schur补的IMR方法
- 避免了传统CMS中最昂贵的计算步骤
- 利用对偶划分的子结构模态近似界面模态
- 显著降低内存占用

5. 算子自适应基函数
- 基于局部刚度矩阵主特征向量识别病态方向
- 通过基函数重构过滤高频伪刚性模式
- 在不增加系统自由度的前提下改善病态性

【1. 与本项目有关的研究工作积累和已取得的研究工作成绩】

（一）报告者本人研究工作

1. 不可拉伸弹性棒仿真方法研究

（1）紧凑坐标表示方法
在传统表示方法下，Cosserat杆需要使用顶点的笛卡尔坐标和单元上的四元数来表示，
这种表示方法使用了过多的自由度（如7n-4个自由度），并且需要许多额外的约束条件，
包括长度约束、四元数单位化约束和轴对齐约束等。

本人提出了一种紧凑坐标表示方法，摒弃了传统的节点位置自由度，转而使用基于根
节点位置以及局部轴角（Axis-angle）的曲率链式参数化体系。在这种表示中，系统的
求解维度被精确缩减至与其内蕴自由度完全一致的3n维。所有约束在表示层面自然满足，
将约束优化问题转化为无约束优化问题。

（2）近线性复杂度预处理器
分析了系统Hessian矩阵的特殊结构，发现其具有块三对角结构。利用这一特点，设计了
一个精心构造的混合预处理器。与广泛使用的块对角预处理器相比，该预处理器可以将
PCG求解器的收敛速度提高一到两个数量级。

更重要的是，证明了该预处理器始终是对称正定的（SPD），这为算法的稳定性奠定了
坚实的理论基础。

（3）与现有方法的对比
与Super-Helices方法相比，本方法实现了更好的性能和稳定性，能够在相对较大的
时间步长下稳定模拟具有数百个顶点和数十个碰撞的不可拉伸Cosserat杆。与RedMax
方法相比，本方法专门针对细长杆优化，效率更高。

2. 多重划分模态综合法研究

（1）相位互补的多重划分策略
观察到传统CMS方法的子结构特征模态可以视为子结构内的加窗傅里叶模态，其中边界
约束固定了基函数的相位。基于这一观察，引入了从第二个空间交错划分计算得到的
基函数。来自两个不同划分的子结构特征模态处于相似的频带，但它们的相位不同，
从而为近似全局特征模态提供了更有效的子空间。

（2）无Schur补的IMR方法
提出了无Schur补及无局部特征求解的界面模态缩减法（SE-free IMR）。利用一个划分
中的界面通常位于另一个划分的子结构内部这一事实，使用子结构静力平衡问题来近似
低频界面模态，直接利用对偶划分中的低频模态基去近乎无损地逼近原始的界面约束空间。

该方法彻底避开了传统方法中最为昂贵的界面刚度耦合计算，在极低维度、高收敛率的
模态基子空间内，实现了针对超大规模系统软硬耦合特征值的高效并行提取。

（3）实验验证
实验表明，与传统CMS方法相比，本方法将精度提高了3个数量级，并在时间和内存成本
上实现了更好的强扩展性和弱扩展性。同时也验证了从CMS继承的优势，即快速局部更新
和超级计算集群上MPI进程间的低通信成本。

3. 畸变单元处理方法研究（初步）

（1）谱几何退化分析框架
提出了将系统病态条件划分为"尺度病态"与"结构性病态"的分类准则。尺度病态可
通过简单的预处理器缓解，而结构性病态需要专门的基函数处理。

（2）算子自适应基函数设计
利用局部刚度矩阵的主特征向量作为物理探针，识别出产生最强人工锁定的方向。沿
着这一方向，设计自适应基函数优化策略。
